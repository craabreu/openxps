ExtendedSpaceCombinedOPES¶

class openxps.ExtendedSpaceCombinedOPES(system, variables, **kwargs)[source]¶

OPES and OPES-explore combined (OPES_COM) on dynamical variables.

This is CombinedOPES acting on the extension system of an ExtendedSpaceSystem: both components deposit kernels on the same dynamical variables, and the total bias is their sum. See ExtendedSpaceOPES for how the variables are handled; the same notes on kernels and extraBias apply.

Parameters:

  • system (ExtendedSpaceSystem) – The ExtendedSpaceSystem to be simulated. The bias force is added to its extension system when this object is created, so it must be created before the simulation or context that uses the system.

  • variables (Sequence[ExtendedSpaceBiasVariable]) – The dynamical variables to bias and their kernel widths, as ExtendedSpaceBiasVariable objects.

  • **kwargs – The remaining arguments of CombinedOPES (temperature, barrier, exploreBarrier, frequency, varianceFrequency, …), except bounded, which follows from the variables’ bounds.

Example

>>> import openxps as xps
>>> from openmm import unit
>>> import cvpack
>>> import openmm
>>> from openmmtools import testsystems
>>> model = testsystems.AlanineDipeptideVacuum()
>>> phi = cvpack.Torsion(6, 8, 14, 16, name="phi")
>>> mass = 3 * unit.dalton*(unit.nanometer/unit.radian)**2
>>> phi0 = xps.DynamicalVariable("phi0", unit.radian, mass, xps.CircularBounds())
>>> kappa = 1000 * unit.kilojoules_per_mole / unit.radian**2
>>> system = xps.ExtendedSpaceSystem(
...     model.system, xps.HarmonicCoupling(phi, phi0, kappa)
... )
>>> opes = xps.ExtendedSpaceCombinedOPES(
...     system,
...     [xps.ExtendedSpaceBiasVariable(phi0, 18 * unit.degrees)],
...     temperature=300 * unit.kelvin,
...     barrier=20 * unit.kilojoules_per_mole,
...     exploreBarrier=10 * unit.kilojoules_per_mole,
...     frequency=100,
...     varianceFrequency=None,
... )
>>> integrator = openmm.LangevinMiddleIntegrator(
...     300 * unit.kelvin, 1 / unit.picosecond, 2 * unit.femtosecond
... )
>>> integrator.setRandomNumberSeed(1234)
>>> simulation = xps.ExtendedSpaceSimulation(
...     model.topology,
...     system,
...     xps.LockstepIntegrator(integrator),
...     openmm.Platform.getPlatformByName("Reference"),
... )
>>> context = simulation.context
>>> context.setPositions(model.positions)
>>> context.setVelocitiesToTemperature(300 * unit.kelvin, 1234)
>>> context.setDynamicalVariableValues([180 * unit.degree])
>>> context.setDynamicalVariableVelocitiesToTemperature(300 * unit.kelvin, 1234)
>>> opes.step(simulation, 200)
>>> opes.getNumKernels()  # each component merged its second kernel
(1, 1)
