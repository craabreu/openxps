ExtendedSpaceOPES¶

class openxps.ExtendedSpaceOPES(system, variables, **kwargs)[source]¶

On-the-fly probability enhanced sampling (OPES) of dynamical variables.

A bias potential is applied to dynamical variables of an ExtendedSpaceSystem to enhance the sampling of the physical coordinates coupled to them. This is OPES acting on the extension system: OPES and OPES-explore (exploreMode=True), multiple walkers and all other options are those of openmm-opes, documented there.

Parameters:

  • system (ExtendedSpaceSystem) – The ExtendedSpaceSystem to be simulated. The bias force is added to its extension system when this object is created, so it must be created before the ExtendedSpaceSimulation or ExtendedSpaceContext that uses the system.

  • variables (Sequence[ExtendedSpaceBiasVariable]) – The dynamical variables to bias and their kernel widths, as ExtendedSpaceBiasVariable objects. Variables with NoBounds are rejected, since the bias is stored on a finite grid. Periodic and reflective variables cannot be mixed.

  • **kwargs – The remaining arguments of OPES (temperature, barrier, frequency, varianceFrequency, …), except bounded, which follows from the variables’ bounds.

  • note:: (..) – Kernels are those of openmm-opes: Gaussian by default and minimum-image on periodic variables, whereas ExtendedSpaceMetadynamics uses von Mises kernels. sigma keeps its openmm-opes meaning: with varianceFrequency=None, the standard deviation of the unbiased distribution.

  • note:: – extraBias entries are evaluated in the extension context, so they must be forces of the extension system, such as other samplers on it.

  • note:: – To restart, save the sampler with getState() alongside the simulation’s state, and after setState() on a new sampler call updateContext() on the new context (or take a step): until then, the context holds no bias and getBiasEnergy() returns minus the barrier.

Example

>>> import openxps as xps
>>> from openmm import unit
>>> import cvpack
>>> import openmm
>>> from openmmtools import testsystems
>>> model = testsystems.AlanineDipeptideVacuum()
>>> phi = cvpack.Torsion(6, 8, 14, 16, name="phi")
>>> mass = 3 * unit.dalton*(unit.nanometer/unit.radian)**2
>>> phi0 = xps.DynamicalVariable("phi0", unit.radian, mass, xps.CircularBounds())
>>> kappa = 1000 * unit.kilojoules_per_mole / unit.radian**2
>>> system = xps.ExtendedSpaceSystem(
...     model.system, xps.HarmonicCoupling(phi, phi0, kappa)
... )
>>> opes = xps.ExtendedSpaceOPES(
...     system,
...     [xps.ExtendedSpaceBiasVariable(phi0, 18 * unit.degrees)],
...     temperature=300 * unit.kelvin,
...     barrier=20 * unit.kilojoules_per_mole,
...     frequency=100,
...     varianceFrequency=None,
... )
>>> integrator = openmm.LangevinMiddleIntegrator(
...     300 * unit.kelvin, 1 / unit.picosecond, 2 * unit.femtosecond
... )
>>> integrator.setRandomNumberSeed(1234)
>>> simulation = xps.ExtendedSpaceSimulation(
...     model.topology,
...     system,
...     xps.LockstepIntegrator(integrator),
...     openmm.Platform.getPlatformByName("Reference"),
... )
>>> context = simulation.context
>>> context.setPositions(model.positions)
>>> context.setVelocitiesToTemperature(300 * unit.kelvin, 1234)
>>> context.setDynamicalVariableValues([180 * unit.degree])
>>> context.setDynamicalVariableVelocitiesToTemperature(300 * unit.kelvin, 1234)
>>> opes.step(simulation, 200)
>>> opes.getNumKernels()  # the second kernel merged into the first
1
